# ÄlykäsKalenteri

ÄlykäsKalenteri is a smart calendar application made with HTML, CSS, and JavaScript.

## Features

- Month navigation
- Add events
- Edit events
- Delete events
- Search events
- Dark mode
- Today highlight
- Finnish holidays
- Live clock
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- GitHub
